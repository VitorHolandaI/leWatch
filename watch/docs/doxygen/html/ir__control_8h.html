Detailed Description

Controle IR generico (TV + AC) por hierarquia de classes.

Construido por partes. Peca 1: comandos + raiz IrDevice. Peca 2: familia TV (IrDeviceTV) + encoder NecTV. Peca 3: RokuRefTV (mapa IR de referencia Roku). Peca 4: marcas Roku (TCL/SEMP/AOC) - concretas. Peca 5: LgTV (outra NecTV, mapa LG 0x20DF). Peca 6: RcaTV + TclAndroidTV (RCA via sendRaw). Peca 7: familia AC (IrDeviceAC) + ElectraAC. Peca 8: HAL do Electra (hal_interface.cpp). Peca 9: UniversalTVRemote (registry de TVs). Peca 10: UniversalACRemote (registry de ACs). Peca 11: MideaAC/KomecoMideaAC. Peca 12: LG/Samsung/Toshiba/Springer-Midea AC.
