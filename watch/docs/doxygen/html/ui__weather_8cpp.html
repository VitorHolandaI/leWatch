Detailed Description

Weather + news block shown inside the WiFi menu when connected.

Free, keyless sources:

  • Weather: Open-Meteo (https, no key) for Campina Grande - PB.
  • News: G1 RSS (https, no key), first headlines from <title>.

HTTP runs in a FreeRTOS task (blocking) and writes static buffers; an LVGL timer polls a flag and updates the labels from the LVGL thread.
