◆ hw_radio_sleep()

void hw_radio_sleep ( )

Put the LoRa radio into low-power sleep.

The radio is not used outside the LoRa apps, so it is slept at boot and again when the LoRa screen is closed. Reconfiguring via hw_set_radio_params() wakes it automatically.
