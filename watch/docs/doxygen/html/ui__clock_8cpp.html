Detailed Description

Clock tools app: Stopwatch, Countdown and Alarm (with MODO ALARME).

MODO ALARME arms the PCF8563 RTC alarm and deep-sleeps the watch (everything off but the RTC). At the set time RTC_INT wakes the chip; the boot path (factory.ino) detects it via hw_woke_from_alarm() and calls ui_alarm_ring().
